# Support

> **Portuguese version:** [Suporte](SUPPORT.md)

- Usage and operation questions: use [Discussions](https://github.com/luizrn/n8n-monitor/discussions).
- Reproducible bugs: open an [issue](https://github.com/luizrn/n8n-monitor/issues/new/choose).
- Vulnerabilities: follow [SECURITY.en.md](SECURITY.en.md) and do not publish details in issues.

Before requesting help, read the README and `docs/operations.en.md`. Include the operating system, Node version, n8n version, and credential-free logs.
